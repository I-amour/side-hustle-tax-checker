Earshot has been uninstalled. No hard feelings, and thanks for giving it a go.

Everything it knew went with it. Your settings, your history, the language packs Chrome downloaded, all of it was on your machine and none of it was anywhere else, so there is nothing sitting on a server with your name on it. That was the deal from the start.

One thing, just in case. If you removed it because nothing seemed to happen, that is almost always because the channel was already in your own language. Earshot stays quiet when there is nothing to translate rather than cluttering the chat, so in an English-only server it looks identical to being broken. The other usual cause is using the Discord desktop app instead of discord.com in the browser, where extensions cannot run at all. If either of those was it, it is worth one more go in a busy multilingual server.
